# API: THẢO LUẬN NHỎ: CÓ NÊN THÊM BUILD VERSION VÀO FOOTER CỦA OCEANTECHAI?

## Base Path
`/api/v1/build-version`

## Endpoints

### GET /api/v1/build-version
Returns the current application build version.

**Authentication:** None (public read-only metadata)

**Response 200:**
```json
{
  "version": "0.1.0",
  "buildDate": "2026-06-24T12:00:00.000Z"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | Semver from `package.json` (sanitized) |
| `buildDate` | string \| null | ISO timestamp set at build time |

**Response Headers:**
- `Cache-Control: public, max-age=3600, stale-while-revalidate=86400`

**Security Notes (Red Team):**
- Does NOT expose commit hash, git branch, or environment variables.
- Version string validated against semver pattern before response.
- No user input accepted — no injection surface.

**Example:**
```bash
curl -s http://localhost:3001/api/v1/build-version
```

## Notes
Version is automatically derived from `package.json` at build time. Bump `package.json` version and rebuild to update.
